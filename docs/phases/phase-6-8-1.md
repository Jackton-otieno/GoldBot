The three reported tick values were USD 0.10. The documented CFDINDEX formula
and all 144 calculator probes implied USD 1.00 per 0.01 price tick per lot.

broker's intended field units remain unconfirmed.

## Reproduce and review

From GoldBot in PowerShell, with the intended demo terminal already running
and signed in, run the existing diagnostic. Use its default expected server
for the original account or specify the verified demo server with
`--expected-server`. A return code of 1 means rejected or unavailable.
A return code of 0 means current probes were consistent.

```powershell
Set-Location D:\GoldBot
& .\.venv\Scripts\python.exe -B -m tools.diagnose_broker_specs
& .\.venv\Scripts\python.exe -B -m unittest discover
```

The command uses MT5 metadata and calculation APIs only. It does not place
orders, change terminal settings, run the trading entry point, or alter
production risk settings. Connection failures or account mismatches stop
collection and leave validation rejected. Offline tests use fixtures.

The [draft broker inquiry](../../reports/phase_6_8_1/broker-support-inquiry.md)
is unsent. Keep the spec rejected while the mismatch is unresolved. If the
broker cannot corroborate the fields, use an independently verified alternate
demo broker or symbol and rerun the same checks. A corroborated current
snapshot still leaves historical specifications and historical execution
unauthorized. Review this result before Phase 6.8.2.
